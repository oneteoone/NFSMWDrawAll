# NFSMW Draw All

A mod for NFSMW 2005 that allows you to display the entire map. 
NFSMWDrawAll - This is a mod script that removes the restrictions on stimming the map in the game NFS Most Wanted. As a result, you can display the entire map at once using the game engine.

Installation:

1. To install this mod you will need: Ultimate ASI Loader (If you have "dinput8.dll" file in your game folder, you don't need to install this): https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/download/Win32-latest/dinput8-Win32.zip
2. Set it to speed.exe 4GB patch (Large Address Aware flag), for example, using the "4GB Patch" utility: https://ntcore.com/files/4gb_patch.zip
3. Unpack the contents of the archive into the game’s root folder.
4. (Optional) Edit the NFSMWDrawAll.ini file.
5. Launch the game and enjoy the city.

// MinObjectPixels=X is the main parameter that controls rendering. It can be changed in the NFSMWDrawAll.ini file:

2–14: More distant details remain visible, but performance impact is higher.

15–23: Recommended range for a good balance between visuals and performance.

23-40: Far fewer parts, and at the same time, significantly better performance.

I recommend using this mod with NFSU2 Extra Options. To activate the debug camera in NFSMW Extra Options Settings, enable the EnableDebugCamera parameter = 1.
